# Return-delta fixed-price curve lab

`FixedPriceCurveHook` demonstrates custom accounting by consuming the entire exact-input amount in `beforeSwap`, paying output from hook-owned inventory, and returning a `BeforeSwapDelta` that reduces the core concentrated-liquidity swap amount to zero. Tests use a real `PoolManager`, router settlement, and ERC-20 balances in both trade directions.

The curve has an immutable rational price and a per-swap input cap. It is also bound at deployment to one canonical ordered `currency0`/`currency1` pair, fee, and tick spacing. Both pool initialization and swaps validate that full configuration, preventing an unrelated or worthless-token pool from spending inventory prefunded for the intended pair. It rejects exact-output swaps, zero-rounded output, oversized input, and insufficient reserves.

Trader input is credited to the hook as a PoolManager ERC-6909 currency claim. This avoids trying to withdraw physical input before the router has settled it, so a newly initialized singleton with no token float and no concentrated-liquidity position can execute the custom curve. For output, the hook burns any claims it already owns first, then pays only the remainder from physical reserves transferred to the hook. The manager is synchronized before physical ERC-20 or native settlement. A claim is an accounting right backed by the corresponding currency held by the PoolManager; it is not an additional physical reserve in the hook contract. Tests exercise claim creation and reuse in both directions, plus native settlement.

This is a learning implementation. It has no oracle, spread, fee, reserve rebalancing, claim redemption or reserve withdrawal path, access control, or protection against a stale price being arbitraged. Raw token units must use compatible decimals. Physical balances and ERC-6909 claims must both be included when monitoring inventory. Production use requires inventory management, price updates with safety bounds, decimal normalization, slippage and deadline controls, pause and recovery mechanisms, and independent security review.
